# TOCA Race Driver 3 Recompilation Acceptance Checklist

The first release target is the North American PS2 disc `SLUS-21182` v1.02. Players supply their own disc image or extracted disc files. Close the Windows 11 milestone when sections 1 and 2 pass on a release candidate. Advertise each additional platform or disc revision after its own verification in section 3.

## 1. Windows 11 end-to-end test

- [x] Build the pinned recompilation, boot the original ISO to the main menu, and drive a World Tour race without PCSX2.
- [x] Create and format a virtual memory card, create a profile, and load it in a new runner process.
- [x] Finish both World Sprintcar Series rounds. Exit after round one, restore the standings from the memory card, and finish round two. Confirm the game closes the championship after the final autosave and a second restart.
- [x] Finish World Sprintcar Series in 6th place or higher on an isolated profile. The test finished tied for 4th with 125 points. After a cold launch, the same card restored the cup and access to US Speedtruck Challenge in Pro Career and Bonus 1960's Grand Prix in Free Race. The version 10 SPU2 runner repeated the second-round finish, wrote a new autosave, and restored both unlocks from that card. [Verification evidence](native-recompilation.md#verify-cup-and-unlock-persistence)
- [x] Finish all four US SpeedTruck Challenge rounds on the prepared Windows runner with no detected compiler. Cold starts between rounds restored 25, 50, and 75 points. [Verification evidence](native-recompilation.md#verify-us-speedtruck-challenge-across-cold-starts)

- [x] Verify a clean Windows Sandbox startup using the prepared launcher and the original ISO. Create and reload a profile, reach Oschersleben, and verify the SDL virtual controller in the guest. - [x] Finish World Sprintcar Series from the final-straight checkpoint in Windows Sandbox, write the award through the game's autosave, and load the awarded card in a fresh process. [Sandbox evidence](native-recompilation.md#windows-sandbox-verification)
