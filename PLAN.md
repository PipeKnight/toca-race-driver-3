# TOCA Race Driver 3 (PS2) Project Plan

## Objective

Enable players to run the original PS2 release of TOCA Race Driver 3 on modern operating systems. Statically translate the Emotion Engine code from the player's disc on their machine and let a portable PS2 runtime read the original disc data. Use runtime tracing to diagnose compatibility issues and understand the formats needed for mods.

The first native milestone is to build the North American `SLUS-21182` revision `1.02` on Windows 11, boot it from the original ISO, reach the main menu, and drive in a race. The existing PCSX2 run provides a reference for startup and rendering. Repeat the native test on each platform before listing it as supported.

Use the [acceptance checklist](docs/acceptance-checklist.md) to track end-to-end play, full-game compatibility, and release verification for each platform.

## Work items

1. **Verify startup in PCSX2.** Boot `SLUS-21182` version `1.02` from the local disc copy, reach the main menu, and start a race. Record the disc revision and emulator settings so the test can be repeated.
2. **Verify a native recompilation on Windows 11.** Evaluate a pinned build of `ps2-native-recomp`. Capture the first boot, menu and race, and use the PCSX2 reference to diagnose divergences. Keep the generated source, binaries, captures, and logs local. [ps2-native-recomp](https://github.com/exoteric33/ps2-native-recomp)
3. **Verify native Linux and macOS builds.** Repeat the Windows test on those platforms, then check controls, saving, and subsequent launches. Apply the release requirements in [AGENTS.md](AGENTS.md) as packaging is introduced.
4. **Investigate custom tracks and cars.** Trace `RDH.DIR` and `RDH_*.HUG` lookups and identify the assets and registration data for a known track and car. First test a local replacement of one resource in an existing slot. Use that result to determine what additional work new slots need, including menus, collision, checkpoints, and AI paths for tracks.
5. **Contribute to RD3_BD7sTools.** Evaluate the existing tools, including the converter from PSP track models to the PC format. Compare the formats they handle with what we learn about the PS2 version. Identify a small improvement and offer to help through the upstream repository. Start with a reproducible example, a documentation improvement, or a small fix that fits the maintainer's priorities. [RD3_BD7sTools](https://github.com/BuilderDemo7/RD3_BD7sTools)
6. **Bundle the next Windows preview as a portable executable.** Embed the setup files in the launcher, keep progress in the existing data directory, and verify first launch and direct reuse on clean Windows from the single executable.
